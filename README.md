Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun.

`main.ts` writes a two-part micro-confession to `/output/entry.txt`: a `To:` line naming who it was meant for, plus the unsent message itself, one line written exactly as it was typed.

Entry:

```
To: Mara
I still check whether you're online before I text anyone else, and I hate that I do.
```

Run with Node 22: `node main.ts`.
